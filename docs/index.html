↑  quickstart

Try it on the bundled demo app in a few minutes.

Before you start: Python 3.11+, git and uv. Install uv with curl -LsSf https://astral.sh/uv/install.sh | sh or brew install uv.
Optional: the Entire CLI (entire plugin install graph) gives the agent code-graph tools. Upshift still works without it.

1
git clone https://github.com/harsh-madhav/upshift.git && cd upshift
2
uv sync
3
uv run upshift bump --repo demo/shop_app --package pydantic --to 2 --dry-run  # no key needed: shows what breaks
4
cp .env.example .env  # then in .env set, for example:
UPSHIFT_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-...
5
uv run upshift bump --repo demo/shop_app --package pydantic --to 2

Ends with [upshift] OK: 16 passing, 0 new failures. Report: …/UPSHIFT_REPORT.md. The fixed code is in .upshift/runs/<run-id>/repo/: your repo is never edited in place.

6
uv run upshift scan --repo demo/shop_app  # fix known vulnerabilities
7
uv run upshift python --repo demo/shop_app --to 3.12  # move to Python 3.12

On your own project: --repo takes a local path or a git URL, and the project needs a pytest suite.
watch needs the fake acme API running first: see the API drift demo.
Providers: anthropic · openai · azure-openai · litellm · bedrock. Bring your own credentials: an API key, plus the endpoint for Azure; Bedrock uses an AWS profile (UPSHIFT_AWS_PROFILE).
Crashed run? uv run upshift resume <run-id>. The run id is printed at the start, and is the folder name under .upshift/runs/.
Providers, every option and troubleshooting: the README.
