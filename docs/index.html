↑  four commands

Upgrade one package, fix every known vulnerability, move to a newer Python, or get off an API before it shuts down.

bump

Upgrade a package and fix the code it breaks.

upshift bump --repo . --package pydantic --to 2

pydantic 1 → 2: 16/16 passing, only models and orders changed.

scan

Find vulnerable deps (pip-audit / OSV) and fix each one.

upshift scan --repo .

jinja2: 4 CVEs fixed, 21 passing. requests: pin change only, no model calls.

python

Move the Python version everywhere it's pinned, then fix.

upshift python --repo . --to 3.12

3.10 → 3.12: 26 passing, 0 new failures.

watch

Spot third-party APIs being retired (Deprecation / Sunset headers in neatlogs traces) and migrate before the shutdown.

upshift watch --repo . --neatlogs

acme v1 → v2: 22 deprecated calls found, 30/30 passing after the sunset.

↑  quickstart

Try it on the bundled demo app in about a minute.

1
git clone https://github.com/harsh-madhav/upshift.git && cd upshift
2
uv sync
3
uv run upshift bump --repo demo/shop_app --package pydantic --to 2 --dry-run  # no key needed: shows what breaks
4
cp .env.example .env  # set UPSHIFT_PROVIDER and your key
5
uv run upshift bump --repo demo/shop_app --package pydantic --to 2

Needs Python 3.11+, uv, and optionally the Entire CLI (entire plugin install graph) for code-graph tools.
Providers: anthropic · openai · azure-openai · litellm · bedrock. Bring your own key.
Crashed run? uv run upshift resume <run-id>
